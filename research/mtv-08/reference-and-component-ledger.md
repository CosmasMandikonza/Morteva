## 3. Explicitly rejected / restricted (the counterexample list docs/03 requires)

1. **Skiper UI as a system** — attribution-required free tier, paid premium, brand-imitation provenance (Nike/Apple/Vercel/Uniswap/Aave recreations, author-acknowledged), marketing-first catalog with no financial-console primitives. Restriction: at most one audited free utility component with visible attribution, and only if it beats a Cult UI equivalent — currently none does.
2. **React Bits Pro / Cult UI "AI SDK Agents" blocks** — paid; no purchase made; adopting paid sources is a founder decision with a receipt.
3. **Awwwards site cloning** — copyrighted art direction; study only.
4. **Hover-only financial detail anywhere** — docs/03 non-negotiable; rules out hover-card patterns for amounts/status.
5. **Decorative payment-button animation** (Border Beam/Cosmic buttons on "Execute payment") — motion must never make spending feel casual; primary financial CTAs get quiet, high-contrast treatment in both visual directions.
6. **Green-for-SUBMITTED** — both directions reserve green strictly for provider-verified terminal states (see proposals §status semantics).

## 4. Awwwards art-direction study (taste calibration, no assets)

What the awarded fintech work above teaches, translated into MOTERVA constraints:

- **VELTO (2026 nominee):** clear transfer totals and honest "illustrative data, no real payments" labeling win juries with _clarity_, not ornament. → MOTERVA: tabular totals, explicit environment labels everywhere.
- **Contiant (2023 HM):** B2B banking credibility = restrained palette, generous whitespace, one accent. → MOTERVA: single-accent discipline in Direction A.
- **Sunbit (2020 HM):** motion as narrative ("smooth transitions, slide-in effects") but in service of a story. → MOTERVA: motion budget spent on state transitions (reserve→approve→submit→verify), not idle decoration.
- **2026 SOTD typography (Grids/Obys, MECHA):** current award typography is large editorial display + quiet mono details. → MOTERVA: display face only on screen titles; working data uses the tabular text face.

## 5. Implementation-time obligations when importing any ledger row

Per docs/03 §Procedure 4, each import must log: exact component name, canonical URL, copied file path, dependencies added, license/attribution line placed in `NOTICE`/credits, approved UX use, observed keyboard/screen-reader behavior (re-verified in copied source, not assumed from docs), and performance notes. Commons Clause (React Bits) additionally forbids ever re-exporting those files as a library.
