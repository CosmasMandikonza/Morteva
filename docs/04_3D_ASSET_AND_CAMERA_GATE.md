# 3D experience: asset-first, evidence-linked and truthful

## Goal
One outstanding 3D flagship is a visual *view of the financial product*, not the finance engine itself. Portfolio financial logic must work when WebGL is unavailable. Prove extensibility through a second typed physical adapter only after first path works.

## First choice gate
Compare (A) offshore inspection drone and (B) underwater vehicle using real candidate licensed models, achievable camera fidelity, mission story, financial relevance, rigging/animation, rendering cost and time risk. Do not precommit based on image searches.

## Required asset manifest
Each chosen asset: author, source URL, downloaded file identity/hash, license, copyright/attribution, exact usage rights, model scale and coordinate system, rigging/animation, texture quality, polygon/draw-call counts and expected loading behavior. No unlicensed brand assets; marketing reference photos are not licensed production 3D models.

## Rendering acceptance
- Correct recognizable physical proportions, plausible materials, suitable environment lighting, believable speeds/orientation, shadows/atmosphere and camera FOV.
- Camera storyboard: overview, object focus, event focus, selected intervention, return-to-overview.
- Selection and zoom must not clip the asset, obscure text or overlap the finance inspector.
- A single deterministic mission time/event source drives 3D, charts, decision room, finances and replay.
- Add WebGL context-loss handling and usable 2D equivalent. Reduced-motion disables unnecessary camera choreography.
- Use measured adaptive performance, lazy loading and asset compression only where appropriate.

## Evidence capture gate
Record real screenshots: 1440x900 overview, selected asset, fault state, revised plan, Airwallex submitted vs verified, Metal receipt, 320/390px responsive, camera zoom extrema, browser zoom, context lost/fallback, reduced motion. Attach measured FPS/device/browser/resolution, loading time and approximate scene draw calls/triangles. Performance targets are not measured achievement.
